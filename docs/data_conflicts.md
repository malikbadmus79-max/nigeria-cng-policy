# Data Conflicts Log

Discrepancies found during desk research, and how the project treats each one. Logging these openly is a credibility asset: put a short version in the paper's methodology section.

| ID | Issue | Values | Sources | Treatment |
|---|---|---|---|---|
| C1 | Vehicles converted vs kits deployed | 120,000+ vehicles vs 93,845 kits (same report) | S01 | Report both; use 93,845 as the conservative figure; ask Pi-CNG how "converted" is defined |
| C2 | "12% adoption" is mislabelled | 12% matches 120,000 ÷ 1,000,000 target, i.e. progress to target, not market penetration | S03, S01 | **Correct in problem statement:** describe as "12% of the 2027 target" |
| C3 | States with active CNG stations | 28 vs 23 states (both with 90 stations) | S01, S11 | Cite as "23–28 states" until a station list is obtained |
| C4 | Fuel efficiency level | 10.67 km/scm (Dataphyte) vs ~6.8 km/scm implied by official benchmark | S20, S05 | The CNG:petrol ratio is consistent (~1:1), so model savings as a ratio; test absolute km/day in survey |
| C5 | Implausible daily saving | "₦70,330 daily saving for a CNG sedan" vs ride-hailing fuel spend of ~₦20,000/day | S11, S21 | Exclude; flag as likely error |
| C6 | Conversion cost | ₦300k – ₦1.5m across sources; free for commercial vehicles (2024) | S02, S17, S20, S05 | Use low/mid/high scenarios; get Lagos quotes |
| C7 | CNG price | ₦230, ₦318, ₦380, up to ₦500+/scm | S13, S11, S10 | Scenarios; record actual pump prices during survey |
